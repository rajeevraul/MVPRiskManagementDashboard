# MVPRiskManagementDashboard
MVP Risk Management Dashboard

[Report and Documentation.pdf](https://github.com/user-attachments/files/27113675/Report.and.Documentation.pdf)

Quick start:

1) cd MVPRiskManagementDashboard
2) python -m pip install uv (if uv not installed already)
3) python -m uv sync
4) python run_app.py
5) http://localhost:8501  (if not autolaunched)
